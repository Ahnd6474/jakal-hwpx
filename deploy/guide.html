서버 없이 내 컴퓨터에서 확인하기

Windows·macOS·Linux의 Docker 로컬 실행. 도메인이나 인증서를 준비할 필요가 없습니다.

Windows라면 더 간단한 방법이 있습니다.
Windows 실행 패키지 ZIP을 풀고 시작.cmd 또는 Jakal.exe를 실행하면 Docker·Python·Node.js 설치 없이 사용할 수 있습니다. 아래는 Docker가 있는 컴퓨터를 위한 대안입니다.

1. 준비

  1. Docker Engine 28 이상과 Compose v2를 설치하고 실행해 두세요. Docker Desktop을 사용한다면 Linux 컨테이너 모드를 사용합니다.
  2. Jakal-Server ZIP 전체를 압축 해제하세요. 첫 실행에는 이미지·의존성을 내려받기 위한 인터넷 연결이 필요하며, 준비가 몇 분 걸릴 수 있습니다.

2. 시작

Windows: 압축을 푼 폴더의 StartLocal.cmd를 더블클릭하세요. 준비가 끝나면 브라우저가 열립니다.

macOS·Linux: 터미널에서 압축을 푼 폴더로 이동한 뒤 실행하세요.

sh local.sh start

소스 저장소에서 실행한다면 sh deploy/local.sh start를 사용합니다. 소스에서 시작할 때는 웹 화면도 처음에 함께 빌드합니다.

3. 브라우저에서 열기

http://127.0.0.1:18988/로 접속하세요. 새 문서·샘플 또는 직접 올린 HWP·HWPX로 확인할 수 있습니다. 편집·검증·다운로드와 외부 도구 연결도 사용할 수 있습니다.

중지와 다시 시작

Windows는 StopLocal.cmd로 중지하고 StartLocal.cmd로 다시 시작합니다. macOS·Linux는 다음 명령을 사용하세요.

sh local.sh stop
sh local.sh start

중지해도 Docker의 문서 저장 볼륨은 유지됩니다. 업로드 문서는 기본 24시간 임시 보관되므로 필요한 결과는 다운로드해 별도로 보관하세요. 패키지를 다른 PC로 옮길 때에는 문서 파일도 따로 옮겨 다시 올립니다.

상태·로그 확인

sh local.sh status
sh local.sh logs

Windows PowerShell에서는 .\local.ps1 -Action status 또는 .\local.ps1 -Action logs를 사용합니다.

문제 해결

Docker에 연결할 수 없거나 버전 오류가 나옵니다

Docker를 먼저 켜고 준비가 끝난 뒤 다시 실행하세요. docker version으로 서버 버전을, docker compose version으로 Compose v2를 확인할 수 있습니다. Engine 28 이상을 사용하세요.

18988번 포트가 이미 사용 중입니다

다른 포트로 시작할 수 있습니다. 같은 포트 설정을 유지해 다시 실행하세요.

# macOS·Linux
JAKAL_LOCAL_PORT=18989 sh local.sh start

# Windows PowerShell
$env:JAKAL_LOCAL_PORT='18989'
.\local.ps1 start

이때 주소는 http://127.0.0.1:18989/입니다.

Windows에서 PowerShell 스크립트 실행이 제한됩니다

실행 정책을 변경하는 대신 패키지 폴더의 터미널에서 Docker 명령을 직접 사용할 수 있습니다.

docker compose -p jakal-local -f compose.local.yaml up -d --build --wait --wait-timeout 240
docker compose -p jakal-local -f compose.local.yaml stop
네트워크 주소가 다른 Docker 작업과 충돌합니다

로컬 구성의 주소를 함께 변경하세요. 예를 들어 macOS·Linux에서 다음과 같이 실행합니다.

JAKAL_LOCAL_SUBNET=172.30.90.0/29 JAKAL_LOCAL_PROXY_ADDRESS=172.30.90.2 JAKAL_LOCAL_APP_ADDRESS=172.30.90.3 sh local.sh start

기존 로컬 네트워크가 있다면 먼저 docker compose -p jakal-local -f compose.local.yaml down으로 정리한 뒤 새 주소로 시작하세요. --volumes를 추가하지 않으면 문서 저장 볼륨은 유지됩니다. 회사 네트워크와 겹치지 않는 주소를 선택합니다.

다른 사람에게 접속 주소를 보내고 싶습니다

127.0.0.1은 각자 자신의 컴퓨터를 가리킵니다. 다른 컴퓨터에는 패키지를 전달해 그 컴퓨터에서 실행하세요. 인터넷 공개 배포는 별도 서버와 도메인을 준비한 뒤 기존 StartServer.cmd 또는 sh manage.sh start를 사용합니다.

이 안내는 파일을 직접 열어 읽을 수 있습니다. 로컬 실행은 해당 PC에서만 접속하도록 구성되어 있으며, 기존 공개 배포 구성과 별도로 실행됩니다.
