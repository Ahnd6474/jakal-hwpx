다른 PC에서도 바로 시작하세요

Windows용 실행 패키지 · Python, Node.js, Docker, 한글 프로그램을 따로 설치할 필요가 없습니다.

가장 간단한 방법: 압축 풀고 실행

  1. Windows용 ZIP 전체를 다른 PC로 옮깁니다.
    Jakal-Workspace-…-windows-x64.zip을 USB나 파일 전송으로 복사하세요. 실행 파일 하나만 옮기면 실행되지 않습니다.
  2. ZIP을 우클릭하고 ‘압축 풀기’를 선택합니다.
    압축 파일 안에서 바로 실행하지 말고, 문서 폴더 등 쓰기 가능한 일반 폴더에 모두 풀어 주세요.
  3. 압축을 푼 폴더에서 시작.cmd를 더블클릭합니다.
    Jakal.exe를 직접 실행해도 됩니다. 편집기 실행 창이 나타나고 기본 브라우저에서 사이트가 열립니다.
  4. HWP·HWPX를 열어 편집합니다.
    샘플 열기나 새 문서로 먼저 확인할 수도 있습니다. 필요한 수정 저장·검증을 마친 뒤 다운로드하세요.

서버나 도메인이 없어도 됩니다

웹 브라우저를 사용하지만 편집기는 이 PC에서 실행됩니다. 보통 http://127.0.0.1:18987/에서 열리며, 포트가 사용 중이면 실행 창에 표시된 다른 주소를 사용합니다. 실행에 필요한 파일은 패키지에 들어 있습니다.

사용 중 기억할 것

브라우저만 닫았을 때실행 창의 편집기 열기를 누르면 다시 열립니다. 실행 창은 작업하는 동안 켜 두세요.
작업을 마칠 때문서를 저장·다운로드한 뒤 실행 창의 종료를 누르세요. 단순히 브라우저 탭을 닫으면 편집기는 계속 실행됩니다.
저장 폴더실행 창의 저장 폴더 열기에서 확인합니다. 앱의 임시 자료는 %LOCALAPPDATA%\JakalWorkspace에 저장되며, 업로드 문서의 기본 보관 기간은 24시간입니다. 완성본은 다운로드해 보관하세요.
다른 PC로 문서 이동패키지 ZIP과 별도로 원본·다운로드한 문서 파일을 옮겨 새 PC에서 다시 여세요. 실행 패키지를 복사하면 문서와 브라우저 세션까지 옮겨지는 것은 아닙니다.
MCP 연결문서 상단의 보기 메뉴 → 외부 도구 연결에서 설정을 발급하세요. 새 PC의 실행 경로와 주소가 다를 수 있으므로 그 PC에서 다시 발급한 설정을 사용합니다.

화면이 열리지 않을 때

실행 파일이나 폴더가 없다고 나옵니다

ZIP 전체를 새 폴더에 다시 풀어 주세요. Jakal.exe, app, runtime 폴더가 같은 위치에 있어야 합니다.

브라우저가 자동으로 열리지 않습니다

실행 창이 ‘실행 중’으로 바뀌면 편집기 열기를 누르거나, 표시된 주소를 브라우저 주소창에 직접 입력하세요. 실행 창이 닫혀 있으면 시작.cmd를 다시 실행하세요.

8000번 주소가 안 열립니다

이 패키지는 보통 18987번을 사용합니다. 이전 PC나 개발 환경의 주소 대신 현재 실행 창에 나온 주소로 접속하세요.

회사·학교 PC에서 스크립트 실행이 제한됩니다

시작.cmd 대신 Jakal.exe를 직접 실행하세요. 프로그램 자체 실행도 제한된 기기라면 해당 기기의 관리 정책을 확인해야 합니다.

문서가 이전 PC처럼 보이지 않습니다

원본에서 사용하는 글꼴이 새 PC에 없으면 줄바꿈·배치가 달라질 수 있습니다. 같은 글꼴이 설치되어 있는지 확인하세요.

macOS·Linux에서도 확인하고 싶습니다

Windows 실행 파일 대신 Jakal-Server ZIP의 로컬 실행 방식을 사용하세요. Docker Engine 28 이상과 Compose v2가 실행 중이면 sh local.sh start로 시작할 수 있습니다. 서버 패키지 안의 guide.html에 안내가 들어 있습니다.

지원 대상: Windows 10·11 x64. 이 안내는 인터넷 연결 없이 파일을 직접 열어 읽을 수 있습니다.
