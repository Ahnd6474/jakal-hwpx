# Nov.zip 참고 개선

> 이 기록 이후 제품의 우선순위를 [범용 문서 편집기 중심](general-editor-priorities.md)으로 바로잡았습니다. 아래 시험지 전용 탭과 기본 양식 설명은 당시 구현 기록이며 현재 기본 UI 구성과 다릅니다.

## 참고한 내용

사용자가 제공한 Nov.zip은 611개 파일 중 HWP 양식 198개를 포함한 데스크톱 시험지 제작 도구의 분석 자료입니다. 설명 문서와 문서 기능·양식·수식 처리 모듈의 구성에서 사용 흐름을 파악했습니다. 첨부 프로그램은 실행하지 않았습니다. 서비스 코드·프롬프트·폰트·이미지·HWP 양식을 제품 소스로 복사하지 않았으며, 기존 편집기와 문서 라이브러리로 별도 구현했습니다. AI 수정은 추가하지 않았습니다.

## 구현한 기능

| 참고한 작업 | 웹에서의 구현 |
|---|---|
| 글자·문단·표·수식·쪽 도구 | 하단 **작업 도구** 또는 Ctrl/Cmd+Shift+K로 검색. 실제 편집기의 커맨드 목록을 열 때 읽고 현재 사용 가능 여부를 표시합니다. 기존 메뉴와 같은 경로로 실행합니다. |
| 반복해서 쓰는 문서 기능 | 분류·검색·키보드 이동과 즐겨찾기 12개. 즐겨찾기는 브라우저에만 보관하며 저장 공간 오류가 편집을 막지 않습니다. |
| 문항·선지·보기·해설 | 6가지 문항 블록. 삽입 전에 내용을 직접 수정하고 미리 볼 수 있습니다. 선지는 세로/가로 배치를 선택합니다. |
| 편집 중 서식과 개체 보존 | 본문의 커서 위치에만 블록을 삽입합니다. 선택 영역·표·글상자·머리말·꼬리말·각주·양식 모드에는 삽입하지 않습니다. 네이티브 텍스트 삽입과 문단 분할을 하나의 스냅샷 명령으로 묶어 실행 취소/다시 실행을 제공합니다. |
| 과목별 양식으로 시작 | 새 문서에서 독자적으로 만든 빈 문서·보고서·문항지·활동지를 생성합니다. 제목과 문항 수(1–20)를 지정할 수 있고 HWPX로 직접 생성하여 기존 분석·버전·검증·다운로드 경로를 사용합니다. |
| 연속 작업의 대기 줄이기 | 블록은 줄마다 화면을 갱신하지 않고 한 작업으로 처리합니다. 작업 도구/새 문서 화면은 열 때 별도 청크로 불러오고, 일반 문서 입력 중에는 커맨드 목록을 조회하지 않습니다. |

새 문서는 서버의 같은 소유권·보관 기간·문서 수 제한을 사용합니다. 입력 필드 길이·문항 수·블록 크기를 제한하며 임의 코드·외부 URL을 실행하는 기능은 없습니다. 도구 실행 직전에 사용 가능 여부와 편집기 인스턴스를 다시 확인하고 중복 실행을 막습니다. 추가 화면을 불러오지 못한 경우에도 오류 경계가 열린 편집기를 유지합니다.

새 양식은 A4/1단 기본 문서입니다. 전문 시험지의 동일한 조판이나 PDF 문항 감지/자동 타이핑을 구현한 것은 아닙니다. 수식은 작업 도구에서 기존 수식 편집기를 열어 입력하며, 블록의 일반 문자열을 자동으로 수식 개체로 변환하지 않습니다.

## 검증

- 프런트엔드: 전체 75개 통과. 검색·범위·블록 제한, 실제 WASM 문서의 다중 문단 삽입 및 스냅샷 복원, 브리지 커맨드 등록·본문 게이트·단축키 메시지, 독립된 React 컴포넌트의 즐겨찾기·블록 미리보기·삽입 요청·양식 제출·도구 오류 복구를 검사했습니다.
- 서버: `python -m pytest web_tests -q` 전체 95개 통과. 양식 4종의 문서 구조/XML/참조 검사, 최대 문항 수, 생성→텍스트 수정→검증→다운로드와 잘못된 생성 요청을 포함합니다.
- 참고 HWP: `2단 양식.hwp`, `kor_right.hwp`, `수학 시험지 양식.hwp`, `eng_box.hwp` 4종을 ZIP에서 로컬 검증 폴더로만 읽어 변환했습니다. 각각 HTTP API 업로드→수정→검증→다운로드→재열기까지 통과했습니다. 업로드 원본 바이트는 유지됐습니다. 이 결과는 선택한 4종에 대한 검사이며 첨부된 198종 전체에 대한 보장을 의미하지 않습니다.
- 로컬 원시 결과: `build/validation/nov-reference/results.json`, `roundtrip-results.json`, `nov-frontend-tests.log`. 참고 양식/결과 파일은 추적하거나 웹 공개 자산으로 배포하지 않습니다.

브라우저 도구의 보안 정책이 로컬 편집기 탭 접근을 거부하여 실제 브라우저 클릭·시각·모바일 화면 검증은 완료하지 못했습니다. 다른 브라우저나 우회 경로를 사용하지 않았습니다. 컴포넌트 검사는 실사이트에 접속하지 않는 독립 테스트이며 시각 검증을 대체하지 않습니다.
