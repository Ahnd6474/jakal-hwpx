# 실제 HWP·HWPX 전체 흐름 검사

검사일: 2026-10-20. 로컬 Python API와 배포용 프런트엔드를 실행하고 실제 브라우저의 파일 선택·입력·저장·검증·다운로드를 사용했습니다. 자동 검사는 별도 임시 저장소와 실제 작업 프로세스를 사용합니다.

## 파일과 확인 범위

| 파일 | 브라우저 검사 | 파일 재열기·API 검사 |
|---|---|---|
| `examples/samples/hwp/기출킬러양식.hwp` | HWPX 변환, 5쪽 원문 표시, 빈 문단과 기존 표 셀 수정, 저장, 검증, HWPX 다운로드, 수정본 재업로드 | 수정 텍스트 일치, 표 4개·수식 124개 보존, 원본 HWP 바이트 보존 |
| `examples/samples/hwpx/math_template_2_formula_fixed.hwpx` | 20쪽·2섹션 원문 표시, 두 섹션의 기존 본문과 표 셀 수정, 저장, 검증, 다운로드, 수정본 재업로드 | 수정 텍스트 일치, 표 20개·수식 522개·그림 9개 보존, 내장 파일 9개 해시 일치 |
| `examples/samples/hwpx/social_security_application_example.hwpx` | — | 업로드 → 표 셀 수정 → 저장 → 검증 → 다운로드 → 재열기·재업로드, 셀 좌표·병합 정보와 수정하지 않은 텍스트 보존 |
| `examples/samples/hwp/generated_native_control_authoring.hwp` | 변환 실패 안내 | 잘못된 변환 결과 차단, 부분 HWPX 미공개, 원본 다운로드 가능 |

표·수식·그림 수는 머리말·바탕쪽을 포함한 전체 XML을 기준으로 합니다. 화면의 편집 가능한 본문 표 수 및 반복 배치되는 원문 표 수와 다를 수 있습니다.

수정 입력에는 한글, 여러 줄, `&`, `<안내>`, 이모지를 포함했습니다. 검증 전 다운로드 차단과, 추가 저장 후 이전 검증·다운로드 URL 무효화도 검사합니다. 내려받은 파일은 XML 구조·참조 검사를 다시 실행하고, 실제 파일에서 수정한 값과 나머지 문서 요소를 비교합니다.

## 발견한 문제와 수정

복합 개체 샘플 HWP의 변환기가 손실 0건을 보고하면서 존재하지 않는 첨부를 참조하는 HWPX를 생성했습니다. 종전에는 이 오류를 편집 기준 버전의 기존 오류로 기록해, 일반 검증 모드에서 다운로드를 허용했습니다.

`server/conversion.py`에서 변환 결과 공개 전에 ZIP 사전 검사에 더해 XML·문서 구조·첨부 참조 검사도 실행합니다. 오류가 있으면 변환을 중단하고 임시 파일을 제거합니다. 원본 HWP는 유지하며, 변환을 다시 시도할 때 사용하는 기존 변환 파일에도 같은 검사를 적용합니다. 잘못된 참조를 임의로 삭제하거나 개체를 제거하지 않습니다.

`web_tests/test_real_roundtrip.py`에는 정상 문서 3개와 위 실패 사례의 회귀 검사를 추가했습니다. 재현 명령:

```powershell
.\.venv\Scripts\python.exe -m pytest web_tests -q
```

최종 결과: 전체 서버 검사 **32개 통과**. 브라우저에서 HWP·HWPX 수정본의 다운로드와 재업로드를 확인했고, 변환 참조 오류 안내도 확인했습니다.

## 문단 줄바꿈 오탐 수정

추가로 제공된 실제 HWP에서 정상 변환 결과가 문서 구조 오류로 차단되는 문제를 확인했습니다. 문단 안의 `hp:lineBreak`를 줄 시작 위치의 길이 계산에서 누락한 것이 원인이었습니다. UTF-16 문자 길이와 명시적 줄바꿈을 함께 계산하도록 수정하고, 화면의 텍스트 추출에서도 줄바꿈 뒤의 텍스트를 보존합니다. 실제 첨부 참조 오류를 차단하는 검사는 유지합니다.

해당 파일은 본문 119개 문단, 표 5개와 그림 5개를 확인했습니다. 그림 바이너리의 해시가 원본과 일치하며, 변환 결과의 줄 배치 정보를 삭제하지 않고 구조·참조 검사를 통과했습니다. 실제 브라우저에서 업로드 → HWPX 변환 → 원문 표시 → 검증 → 다운로드를 확인했고, 다운로드 파일은 변환 결과와 바이트가 같습니다. 개인 문서는 저장소의 샘플이나 테스트에 추가하지 않았습니다.

`web_tests/test_inline_layout.py`에 익명으로 구성한 줄바꿈·공백·이모지 사례와 실제 위치 초과 차단, 화면 텍스트·다운로드 보존 검사를 추가했습니다. 다음 명령으로 서버 및 기존 줄 배치 검사 **62개 통과**를 확인했습니다.

```powershell
.\.venv\Scripts\python.exe -m pytest web_tests tests/test_layout_preservation.py -q
```
