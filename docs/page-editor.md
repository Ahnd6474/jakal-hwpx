# 원문 서식 편집기

문서를 열면 **문서 편집** 탭이 먼저 표시됩니다. 원문을 별도 입력 상자로 분해하지 않고 페이지 위에 커서를 놓아 입력합니다. 문서 목록은 왼쪽 위 버튼으로 열며, 기본 화면에서는 문서가 전체 폭을 사용합니다. **원문 보기**, 기존 텍스트 편집, 표·그림 모아 보기도 유지합니다. 서로 다른 편집 방식의 미저장 변경을 섞지 않도록 먼저 저장한 뒤 전환합니다.

현재는 별도 보기 탭 줄을 **보기 및 도구** 메뉴로 모았습니다. 기본 서식만 표시하며 **모든 도구**·**집중 보기**를 하단에서 전환합니다. 측정 결과와 임시 저장·전송·캐시 개선은 [편집기 최적화](editor-optimization.md)를 참고하세요.

## 연결한 작업

- 글자 입력·선택·복사·붙여넣기와 실행 취소·다시 실행
- 글꼴, 크기, 굵게·기울임·밑줄, 글자 색과 강조
- 문단 정렬·줄 간격·들여쓰기·번호·글머리표
- 표 만들기, 셀 입력, 표 메뉴의 행·열·셀 작업
- 그림·도형·수식·문자표·하이퍼링크 입력 도구
- 편집 용지·여백·쪽 나누기·머리말·꼬리말·각주 도구
- 연속 문서 스크롤·확대/축소·너비 맞춤·도구 접기·편집기 전체 화면

도구는 고정된 문서를 조작하는 편집 엔진의 명령에 연결되어 있습니다. AI 수정은 추가하지 않습니다. 파일 형식별 지원 정도는 개체에 따라 다르며, 한글 프로그램의 모든 기능 및 동일한 인쇄 결과를 보장하지 않습니다. 설치되지 않은 글꼴이나 지원되지 않는 조판은 표시 차이가 날 수 있습니다. 복잡한 문서의 최종 인쇄 배치는 한글에서도 확인해야 합니다.

## 저장과 복원

**수정 저장** 또는 **Ctrl+S**는 현재 편집기의 HWPX를 서버에 보내 새 버전으로 저장합니다. 원본과 이전 파일은 교체하지 않습니다. 서식과 구조 변경을 허용하는 전용 저장 경로 `/api/documents/{id}/studio?revision=N`을 사용합니다. 기존 문단/셀 명령 경로는 그대로 유지합니다.

서버는 소유자·현재 버전·작업 중복을 확인하고, 크기·ZIP·XML·참조·보호 문구·엄격 검증을 적용한 뒤 버전을 공개합니다. 브라우저 엔진도 내보내기의 개체 손실 보고가 0건인 경우에만 파일을 전달합니다. 구조 변경은 의도된 편집일 수 있으므로, 전체 편집 저장에서 개체 수가 원본과 같아야 한다는 조건은 적용하지 않습니다. 저장 후 별도의 현재 버전 검증을 통과해야 다운로드할 수 있습니다.

저장하는 동안 입력을 잠그고, 저장한 파일과 현재 편집기의 바이트 해시를 비교한 뒤 저장 완료를 알립니다. 내보내기 자체가 발생시키는 배치 갱신 이벤트는 추가 입력으로 오인하지 않습니다. 실패하면 미저장 상태를 유지하고, 서버가 이미 저장한 버전이 있으면 그 버전 번호도 화면에 반영합니다.

편집은 브라우저 IndexedDB에도 임시보관합니다. 같은 버전의 임시본은 열 때 복원 여부를 표시하고, 다른 버전의 임시본은 자동 적용하지 않으며 별도로 받을 수 있습니다. 서버 저장 성공 후에만 편집기와 임시본을 정리합니다.

## 로컬 런타임과 빌드

[`@rhwp/editor`](https://github.com/edwardkim/rhwp/tree/v0.8.7/npm/editor)와 Studio v0.8.7을 MIT 라이선스로 사용합니다. 원문 페이지의 커서·선택·IME·서식·개체 도구는 이 엔진에서 제공합니다. 고정 소스 커밋은 `1a76570e833917d15817415a53c09ad61ab3203f`입니다.

`web/scripts/build-studio.mjs`가 고정 소스를 `build/rhwp-studio-source`에 준비하고, 기존 `@rhwp/core` WASM과 로컬 글꼴을 사용해 `web/public/studio`를 생성합니다. 최초 빌드에는 Git과 npm 패키지 다운로드가 필요합니다. `npm run build`는 결과가 없거나 통합 코드가 바뀌면 자동으로 준비합니다. 런타임 자산은 생성물이므로 Git에서 제외하며 라이선스·글꼴 안내를 함께 복사합니다.

편집기는 동일 출처의 `/studio/`에서 실행합니다. 외부 Studio URL을 사용하지 않고, 외부 웹폰트를 끄며, 편집기 CSP의 연결·글꼴·스크립트 출처를 로컬로 제한합니다. 문서를 외부 편집 서비스로 전송하지 않습니다. 열기·저장·내보내기 메뉴는 호스트가 관리하는 embed 모드로 제한해 사이트의 버전·검증 경로를 거치게 합니다.

## 확인한 항목

실제 브라우저에서 원문 직접 입력, 선택 영역의 굵게·크기 변경, 표 만들기와 셀 입력, Ctrl+S 저장 및 검증·다운로드를 확인했습니다. 저장한 HWPX를 다시 열어 텍스트·서식·표 변경과 검증 오류 0건을 확인했습니다. 제공된 HWP의 HWPX를 같은 엔진으로 다시 저장해 문단 텍스트·그림 해시·표 5개의 보존도 확인했습니다. 개인 문서는 테스트 저장소에 추가하지 않았습니다.

서버 및 줄 배치 검사 67개와 프런트엔드 검사 46개가 통과했습니다. 전용 서버 회귀 검사는 `web_tests/test_studio.py`에서 서식·구조 변경, 원본 보존, 검증 전 다운로드 차단, 소유자·버전 충돌, 잘못된 참조, 보호 문구와 CSP를 검사합니다.
