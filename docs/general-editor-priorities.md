# 범용 문서 편집기 중심으로 정리

Nov.zip의 시험지 문서는 편집 기능을 살펴보기 위한 예시다. 제품의 중심은 특정 문서 종류의 생성이 아니라, 사용자가 연 문서의 내용·서식·표·개체·쪽을 편집하고 그 결과를 보존하는 것이다. AI 수정은 추가하지 않는다.

## 이번 변경

- 기본 작업 도구에서 시험지 전용 블록 탭을 제거했다. 실행 취소·다시 실행·찾기·바꾸기·글자 모양·문단 모양·표 만들기·편집용지를 빠른 도구로 제공한다. 검색·분류·즐겨찾기는 그대로 제공하며, 기존 편집기의 동일한 명령과 사용 가능 여부를 사용한다.
- 새 문서의 기본 목록은 빈 문서·일반 보고서·회의록·표 문서다. 기존 API 양식 ID는 호환성을 위해 유지하지만 기본 목록에는 표시하지 않는다. 저장된 사용자 문서와 내용은 변경하지 않는다.
- 고정 편집기 소스에서 글자 모양 설정이 선택 영역이 없을 때 조기 종료하는 경로를 고쳤다. 선택 범위가 있으면 대화상자를 열기 전에 캡처한 범위에 적용한다. 선택이 없거나 빈 선택이면 기존 툴바와 같은 `format-char` 경로로 다음 입력 서식을 예약한다. 주변 본문을 임의로 변경하지 않는다.
- 저장 파일 바이트 일치 검사와 편집기 저장 통지가 성공한 뒤 임시보관 기준 버전을 갱신한다. 저장 확인 실패를 새 버전으로 확정하지 않는다.

## 확인

프런트엔드 전체 검사 77개 통과. 선택 범위/빈 선택/커서만 있는 경우의 서식 적용 경로, 기본 편집 도구의 사용 가능 여부·실행, 범용 양식 제출을 포함한다. 관련 서버 검사 20개 통과(양식·원문 편집 저장·줄 배치). 프로덕션 빌드를 확인했다.

앞선 브라우저 도구의 로컬 접근 차단 때문에 실제 화면 조작과 시각 검증은 이번에도 수행하지 않았다. 독립된 컴포넌트·엔진 검사와 실제 브라우저 검증은 구분한다.

## 이후 개선의 기준

1. 입력·선택·줄바꿈·한글 조합·복사/붙여넣기·실행 취소/다시 실행의 일관성
2. 글자/문단 서식과 표/그림/수식/쪽 설정을 수정한 뒤 저장했을 때의 보존
3. 원문 배치의 충실도, 긴 문서의 응답성과 넓은 편집 영역
4. 오류 시 복구, 버전 충돌 방지, 검증과 다운로드의 정확성

검증하지 않은 한글의 전체 기능이나 모든 문서의 동일 조판을 지원한다고 표시하지 않는다. 특정 양식 추가보다 이 네 기준에서 실제로 발견한 결함을 먼저 해결한다.
